# Telegram Mini App — אח שלי

דף הבית וההרשמה משמשים גם כאפליקציה בתוך טלגרם, וגם כאתר רגיל.

## פתיחה

- כתובת הייצור המאומתת: `https://ah-sheli-telegram-bot.replit.app/`.
- כפתור Menu בצ׳אט פרטי: **🎯** — תווית אייקון קצרה לפתיחת האפליקציה, במקום הטקסט הרחב.
- צורה, צבע וגודל נשלטים בידי לקוח טלגרם; אין ב־Bot API אפשרות לכפות כפתור עגול או מידות מדויקות.
- עובד הבוט מגדיר את תפריט ברירת המחדל באמצעות `setChatMenuButton` בעת ההפעלה.
- פקודות הבוט והגבלת פקודות הניהול למנהל נשארות כפי שהיו.
- `PUBLIC_APP_URL`, כאשר מוגדר, חייב להפנות לכתובת הייצור הציבורית המאומתת ב־HTTPS.
- התפריט בטלגרם אינו מפרסם את קוד האתר: יש לבצע Republish כדי להעלות את שינויי ה־SDK והשרת.

## התאמה לחלון טלגרם

נטען ה־SDK הרשמי מ־`https://telegram.org/js/telegram-web-app.js`.
הגשר מפעיל `ready()` ו־`expand()`, מתאים גובה ושוליים בטוחים, ומתאים את
צבעי חלון טלגרם לעיצוב האתר. כפתור החזרה של טלגרם סוגר את חלונית ההרשמה.
אין כפיית מסך מלא, חסימת גלילה או חסימת הגדלת טקסט.

קישורי הבוט נפתחים באמצעות `openTelegramLink`. Checkout וניהול מנוי ב־Whop
נפתחים באמצעות `openLink`, בלי להחליף את מסמך ההרשמה בתוך האפליקציה.
מצב ההרשמה נבדק מחדש, כולל בחזרה לחלון. אם ה־SDK חסר, נשאר ניווט רגיל בדפדפן.

## זהות ותשלום

מידע לקוח כגון `initDataUnsafe`, וגם הכותרת `X-Ah-Sheli-Mini-App`, **אינם הוכחת זהות**.
הכותרת בוחרת רק את אופן שמירת עוגיית ההרשמה.
אימות הטלגרם הפרטי בקוד, הגנת Origin, בדיקת התשלום בצד השרת והרשאות הבוט
נשארו ללא שינוי. אין הפעלה אוטומטית של מנוי על סמך פתיחת Mini App.

בחלון טלגרם משתמשים בעוגייה נפרדת מסוג `Secure; HttpOnly; SameSite=None; Partitioned`
כדי לאפשר הרשמה גם ב־iframe של Telegram Web בדפדפנים התומכים ב־CHIPS.
באתר רגיל נשארת עוגיית `SameSite=Lax` המקורית. ההפרדה אינה מוחקת משתמשים או מנויים;
היא רק מפרידה בין הפעלות דפדפן. בדפדפנים ישנים החוסמים כל עוגיית צד שלישי
ייתכן שיהיה צורך לפתוח את ההרשמה בדפדפן רגיל או לעדכן את הלקוח.

## בדיקות

בדיקות היחידה מכסות את הגשר, הגבלת קישורים ועוגיות.
בדיקת דפדפן עם SDK מדומה ו־iframe אינה מחליפה בדיקה במכשיר טלגרם אמיתי.
אין לבצע חיובים אמיתיים כחלק מבדיקת תצוגה.
